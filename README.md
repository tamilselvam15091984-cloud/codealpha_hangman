# 🎮 Hangman Game

A simple and interactive **Hangman Game** developed as a beginner-friendly programming project. The game challenges players to guess a hidden word by entering one letter at a time.

## 📌 About the Project

Hangman is a classic word-guessing game where the player needs to identify a secret word before running out of attempts. Each correct guess reveals the position of the guessed letter, while an incorrect guess reduces the number of remaining attempts.

This project is designed to demonstrate fundamental programming concepts through an interactive game.

## ✨ Features

* 🎯 Random word selection
* 🔤 Letter-by-letter word guessing
* ❤️ Limited number of attempts
* ✅ Correct and incorrect guess handling
* 🚫 Prevents repeated letter guesses
* 📊 Displays the current progress of the word
* 🏆 Winning and losing conditions
* 🔄 Option to play again
* 💻 Simple and user-friendly interface

## 🛠️ Concepts Used

* Variables and data types
* Conditional statements
* Loops
* Functions
* Strings
* Arrays / Lists
* User input handling
* Random number generation
* Basic game logic

## 🎮 How to Play

1. Start the game.
2. A secret word will be selected.
3. Guess one letter at a time.
4. If the letter is correct, it will be revealed.
5. If the letter is incorrect, one attempt will be lost.
6. Continue guessing until you find the complete word.
7. Guess the word before all attempts are used to win the game.
